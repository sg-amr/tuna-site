## 記事の追加手順

1.  **`src` フォルダへ移動**
    *  **`src`** フォルダをクリックして開きます。

2.  **新規ファイル作成の開始**
    * `src` フォルダ内のファイル一覧の上部にある **"Add file"** ドロップダウンボタンをクリックし、表示されたメニューから **"Create new file"** を選択します。
        
3.  **ファイル名と内容の入力**
    * **ファイル名を入力します**：`src/` の後に、作成したいMarkdownファイルの完全な名前を入力します。Markdownファイルなので、必ず **`.md`** で終わる名前にしてください
    * ファイル名がそのままURLの名前になります。（例：`my_article.md`なら、`https://ninastan.aoristos.net/my_article`でアクセスできる）
    * **ファイルの内容を記述します**：ファイル名の下にある大きなテキストボックスに、追加したいMarkdown形式のテキストを入力します。
    * ちなみに、上の`preview`タブでどんなふうに見れるか確認可能。

4.  **変更のコミット（保存）**
    * **"Commit changes"** ボタンをクリックします。
    * そのまま流れるままにボタンを押します。

## 既存の記事の更新/修正

1.  **`src` フォルダへ移動**
    *  **`src`** フォルダをクリックして開きます。

2.  **ファイル修正の開始**
    * `src` フォルダ内のファイル一覧の更新したいファイルをクリックして開
    * **ファイルの内容を記述します**：ファイル名の下にある大きなテキストボックスに、追加したいMarkdown形式のテキストを入力します。

4.  **変更のコミット（保存）*
    * **"Commit changes"** ボタンをクリックします。
    * そのまま流れるままにボタンを押します。

## 記事の削除

1.  **`src` フォルダへ移動**
    *  **`src`** フォルダをクリックして開きます。

2.  **ファイルの選択**
    * `src` フォルダ内のファイル一覧の更新したいファイルをクリックして開

3.  *削除**
    * 右上の"・・・"のボタンを押して、ドロップダウンメニューをスクロール→Delete Fileを選択
    * **"Commit changes"** ボタンをクリックします。
    * そのまま流れるままにボタンを押します。
  
      **Webサイトから消えてもネット上には残ってしまうので注意**

## 画像の追加方法

1. **画像を追加したい箇所に画像を読み込むための記号を書き込む**
    * `![](ファイル名)`（ファイル名は拡張子を含む）
2. **画像をアップロード**
    * `/public`フォルダの中にアップロードする

## 注意・ちょっと高度なテクニック

* `src`フォルダの中と、`public`のフォルダの中以外をいじると動かなくなる。(`public`ディレクトリの中の`CNAME`ファイルも)
* 技術の時間にやった*html*がそのまま使えます。

    例：
    ```
    <p style="color: red;">赤くなる</p>
    ```
    表示：
    <p style="color: red;">赤くなる</p>

    *style*属性の中に*css*をかけます。
