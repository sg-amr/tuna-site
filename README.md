
## 記事の追加手順

1.  **このページを開く**
    （すでに完了）

2.  **`src` フォルダへ移動**
    *  **`src`** フォルダをクリックして開きます。

3.  **新規ファイル作成の開始**
    * `src` ディレクトリ内のファイル一覧の上部にある **"Add file"** ドロップダウンボタンをクリックし、表示されたメニューから **"Create new file"** を選択します。
        
4.  **ファイル名と内容の入力**
    * **ファイル名を入力します**：`src/` の後に、作成したいMarkdownファイルの完全な名前を入力します。Markdownファイルなので、必ず **`.md`** で終わる名前にしてください（例: `new_document.md`）。
    * ファイル名がそのままURLの名前になります。（例：my_article.mdなら、https://tuna.aoristos.net/my_articleでアクセスできる）
    * **ファイルの内容を記述します**：ファイル名の下にある大きなテキストボックスに、追加したいMarkdown形式のテキストを入力します。

5.  **変更のコミット（保存）**
    * ページの下部までスクロールします。
    * **"Commit changes"** ボタンをクリックします。
    * そのまま流れるままにボタンを押します。
